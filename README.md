# ShopSphere – E-commerce Web Application

ShopSphere is a Django-based e-commerce web application where users can browse products, add products to their cart, place orders and manage their orders.

## Features

- User Registration and Login
- Product Listing and Product Details
- Search Products by Name
- Filter Products by Price and Stock
- Sort Products
- Pagination
- Add to Cart
- Increase and Decrease Cart Quantity
- Checkout and Place Orders
- My Orders
- Cancel Orders
- REST APIs using Django REST Framework

## Technologies Used

- Python
- Django
- Django REST Framework
- HTML
- CSS
- SQLite
- Git and GitHub

## Project Status

This project is developed for learning and practicing Django web development and REST API development.
